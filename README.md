# Pixel Quest: Shadow Runner

A polished original 2D side-scrolling platformer built with Flutter + Flame.

## Foundation
- Mobile-first landscape gameplay
- Original character and visual direction
- Player movement, jump and double jump
- Coyote time and jump buffering
- Reusable level data
- Five world definitions
- Touch-control foundation
- Flutter/Flame separation

## Development
```bash
flutter pub get
flutter analyze
flutter test
flutter build apk --release
flutter build appbundle --release
```
